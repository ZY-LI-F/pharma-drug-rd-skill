# Regulatory Source Map for FDA / NMPA Based Skills

This repository now includes CMC, GMP, and eCTD-oriented skills that are designed to follow **official FDA and NMPA/CDE sources first**.

## FDA sources used as primary authority

### eCTD / submission format
- FDA Electronic Common Technical Document (eCTD)
- FDA eCTD Resources
- FDA eCTD v4.0 implementation page
- FDA guidance: Providing Regulatory Submissions in Electronic Format — Certain Human Pharmaceutical Product Applications and Related Submissions Using the eCTD Specifications
- FDA Submit Using eCTD

### CMC
- FDA IND Applications for Clinical Investigations: Chemistry, Manufacturing, and Control (CMC) Information
- FDA pharmaceutical quality resources and search portal for quality guidances
- FDA/ICH quality guidances that commonly govern CMC planning, including Q8, Q9, Q10, Q11, Q12, and Q13 where applicable

### GMP / cGMP
- FDA Current Good Manufacturing Practice (CGMP) Regulations
- FDA Facts About the Current Good Manufacturing Practice (CGMP)
- FDA guidance: Current Good Manufacturing Practice for Phase 1 Investigational Drugs
- FDA guidance: Q10 Pharmaceutical Quality System

## NMPA / CDE sources used as primary authority

### eCTD / submission format
- CDE eCTD 专栏
- 国家药品监督管理局药品电子通用技术文档技术规范 V1.0 及附件包
- 国家药品监督管理局药品电子通用技术文档验证标准 V1.0
- 国家药品监督管理局药品电子通用技术文档实施指南 V1.0
- 《M4模块一行政文件和药品信息》
- 《药品注册申报资料格式体例与整理规范》
- NMPA 关于实施 eCTD 的公告（2021）及扩大实施范围公告（2025）

### CMC / 药学
- 《药品注册管理办法》
- CDE 办事指南中关于申报、电子提交、CTD/eCTD与资料一致性的要求
- CDE 已发布的具体药学研究与评价技术指导原则（应根据品种、剂型、路线、分子类型进一步细化）
- 创新药临床试验期间化学药 CMC 变更技术指导原则（适用于相关情形）

### GMP
- 《药品生产质量管理规范（2010年修订）》
- 相关 NMPA / CDE 发布的附录、检查要求和与药品注册要求衔接的官方文件

## Interpretation rule used in these skills

1. **Official law / regulation beats guidance.**
2. **Regional module rules beat generic CTD habits.**
3. **For modality-specific CMC, product-type guidance beats general templates.**
4. **GitHub examples never override official requirements.**
5. **When FDA and NMPA expectations differ, the skill must separate them instead of forcing a fake unified answer.**
