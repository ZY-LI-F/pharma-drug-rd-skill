# Pharma Drug R&D Skill Suite

A public collection of reusable ChatGPT skills covering key stages of drug research and development.

This repository includes:
- DrugClaw-based evidence and repurposing skills
- Structure prediction and virtual screening skills
- ADMET and molecular property modeling skills
- De novo molecule generation skills
- Clinical study operations skills
- Lab knowledge capture skills

More files will be added in the next commit.
